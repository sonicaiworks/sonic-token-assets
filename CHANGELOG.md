# Changelog

All notable changes to the SONIC public asset package are documented here.

The format follows a simple versioned changelog model.

## [1.0.0] — 2026-09-08

### Added

- Canonical `public/assets/sonic.png` token artwork.
- Vector SONIC waveform mark at `public/assets/sonic.svg`.
- Silver SONIC coin artwork at `public/assets/coin.png`.
- Web-optimized silver coin at `public/images/sonic.webp`.
- Web-optimized red token at `public/images/sonic-red.webp`.
- Shared vector icon at `public/icons/sonic.svg`.
- Primary logo directory at `public/icons/logo/`.
- Black and white monochrome SVG logo variants.
- Raster logo fallbacks at 512px, 256px, and 128px.
- Silver coin raster preview under `public/icons/logo/coin.png`.
- SHA-256 asset manifest at `public/manifest.json`.
- GitHub-styled README documentation across asset directories.
- MIT license with explicit trademark/brand-rights clarification.

### Changed

- Reorganized public assets into `assets/`, `images/`, and `icons/` by runtime purpose.
- Standardized the canonical path contract for token metadata, web imagery, and UI icons.
- Promoted the silver coin as the primary tokenomics/marketing visual.
- Preserved the red SONIC artwork as the canonical token/wallet asset.

### Removed

- Removed the temporary `ROOT_README_ASSETS_SECTION.md` integration snippet.
