## Asset package

This repository package defines the canonical public asset layout used by SONIC Token, SONIC Network applications, documentation, tokenomics interfaces, wallet integrations, and marketing surfaces.

```text
public/
├── README.md
├── manifest.json
├── assets/
├── images/
└── icons/
```

### Primary files

| Asset | Path | Use |
|---|---|---|
| SONIC token artwork | `public/assets/sonic.png` | Token metadata, wallets, docs |
| SONIC vector mark | `public/assets/sonic.svg` | Canonical vector source |
| SONIC silver coin | `public/assets/coin.png` | Tokenomics, marketing, docs |
| Web-optimized silver coin | `public/images/sonic.webp` | Website and application UI |
| Web-optimized red token | `public/images/sonic-red.webp` | Alternate web token visual |
| Primary UI logo | `public/icons/logo/sonic.svg` | Headers, navigation, components |
| Dark logo | `public/icons/logo/sonic-black.svg` | Light surfaces |
| Light logo | `public/icons/logo/sonic-white.svg` | Dark surfaces |
