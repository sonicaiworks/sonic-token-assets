## Public assets

SONIC public assets are organized by runtime purpose:

```text
public/
├── assets/        # canonical source/reference assets
├── images/        # optimized WebP website imagery
└── icons/
    └── logo/      # SVG + raster logo/icon variants
```

Primary paths:

- `/public/assets/sonic.png` — canonical red SONIC token artwork
- `/public/assets/coin.png` — silver SONIC coin artwork
- `/public/assets/sonic.svg` — vector waveform mark
- `/public/images/sonic.webp` — optimized tokenomics/web visual
- `/public/icons/logo/sonic.svg` — primary scalable UI logo
- `/public/icons/logo/sonic-black.svg` — monochrome dark logo
- `/public/icons/logo/sonic-white.svg` — monochrome light logo

See [`public/README.md`](./public/README.md) for the complete asset contract.
